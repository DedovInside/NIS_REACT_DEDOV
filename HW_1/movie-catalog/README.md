## Описание проекта

React + TypeScript веб-приложение для просмотра каталога фильмов с возможностью добавления в избранное, поиска и фильтрации. Приложение использует данные из The Movie Database (TMDB) API и предоставляет современный интерфейс для работы с коллекцией фильмов.

## Инструкции по запуску

**Клонировать репозиторий:**

```bash
   git clone [URL репозитория]
   cd movie-catalog
```

**Установить зависимости:**

```bash
  npm install
```

**Запустить приложение в режиме разработки:**

```bash
  npm run dev
```

**Открыть браузер по адресу:**

[http://localhost:5173](http://localhost:5173)

### 🔧 Дополнительная настройка (опционально)

Для обновления данных фильмов из TMDB API:

1. Получить API ключ на [странице настроек TMDB](https://www.themoviedb.org/)
2. Заменить API_KEY в файле `src/scripts/fetchMovies.js`
3. Запустить скрипт:

```bash
   node src/scripts/fetchMovies.js
```

## Доработки на 9 баллов

### 1. Мемоизация и оптимизация производительности

**Реализовано:**

- `React.memo` для всех компонентов (MovieCard, FilterButtons, ViewModeToggle, MovieModal)
- `useMemo` для дорогостоящих вычислений фильтрации фильмов
- `useCallback` для стабилизации функций-обработчиков

**Обоснование:** Предотвращает лишние перерендеры компонентов, особенно критично при работе с большими коллекциями фильмов (до 4000 элементов). Повышает производительность приложения и улучшает пользовательский опыт.

### 2. Продвинутые CSS-анимации и UI/UX

**Реализовано:**

- Плавные трансформации карточек при наведении (`transform: translateY(-8px)`)
- Анимация появления контента (`@keyframes fadeIn`)
- Градиентная анимация заголовка с эффектом свечения
- Backdrop blur эффекты для современного glass-morphism дизайна
- Smooth-переходы для всех интерактивных элементов

**Обоснование:** Создает современный и привлекательный интерфейс, повышает engagement пользователей и улучшает визуальную обратную связь.

### 3. Семантическая верстка и доступность (a11y)

- Правильная табуляция и фокус

**Обоснование:** Делает приложение доступным для пользователей с ограниченными возможностями, улучшает SEO и соответствует современным стандартам веб-разработки.

### 4. Адаптивный дизайн

Расширенная конфигурация с плагинами:

- `typescript-eslint` - строгая проверка TypeScript
- `eslint-plugin-jsx-a11y` - проверка доступности (a11y)
- `eslint-plugin-import` - контроль порядка импортов

```bash
npm run lint        # проверка
npm run lint:fix    # автоисправление
```

### Prettier

Единый стиль форматирования для всего проекта (`.prettierrc`).

```bash
npm run format          # форматировать все файлы
npm run format:check    # проверить без изменений (используется в CI)
```

При каждом коммите автоматически запускается:

- `eslint --fix` - исправление ошибок линтера
- `prettier --write` - форматирование изменённых файлов

### GitHub Actions CI

Пайплайн запускается на каждый `push` и `pull_request` в `main`/`master`:

1. `npm ci` - установка зависимостей
2. `npm run lint` - проверка ESLint
3. `npm run format:check` - проверка Prettier
4. `npm run test:coverage` - запуск тестов с покрытием
5. `npm run build` - сборка проекта
